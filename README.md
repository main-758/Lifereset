# Life Reset MVP

A free, self-contained browser MVP.

## Run it
Open `index.html` in a browser. No server, database, API key, or paid service is required for this prototype.

## Included
- 30-second six-area scorecard
- Good / Needs Attention / Critical results
- Free plan-generation limit (3 in demo)
- Brain dump intake
- Today / Tomorrow / This Week action plan
- Task check-offs saved in browser local storage
- Share/copy scorecard
- Responsive mobile layout

## Next production step
Replace the local plan generator with a secure backend AI endpoint, add authentication/database, and implement real weekly quota enforcement and paid subscriptions.
